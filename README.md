# DAE Sales and Data Analysis System

A Flask-based web application for analyzing shopping sales data using Python, Pandas, and Matplotlib.

## Features

- Online and Offline sales analysis
- Product-based sales analysis
- Total Sales and Total Cost calculation
- Average Sales and Average Cost analysis
- 1 Month, 6 Months, and 1 Year analysis
- Sales and Cost visualizations
- Customer Review and Rating analysis
- Rating Distribution visualization
- Average Rating Trend
- Customer Reviews display

## Technologies Used

- Python
- Flask
- Pandas
- Matplotlib
- HTML
- CSS
- JavaScript

## Dataset

The project uses `sales_data_large.csv` containing shopping sales, cost, rating, review, and product information.

## How to Run

```bash
pip install flask pandas matplotlib
python app.py
